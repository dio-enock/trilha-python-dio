# 🏦 Sistema Bancário com Python

Projeto desenvolvido como parte da formação Python da [DIO](https://www.dio.me/), com o objetivo de praticar conceitos fundamentais da linguagem Python por meio da construção de um sistema bancário em terminal.

## 🚀 Funcionalidades

* 💰 Depósito de valores
* 💸 Saque de valores
* 📄 Consulta de extrato
* 🔒 Limite de R$ 500 por saque
* 🔢 Limite de 3 saques
* ✅ Validação de valores informados
* ⚠️ Tratamento de entradas inválidas

## 🛠️ Tecnologias

* Python 3
* Git
* GitHub

## ▶️ Como executar


```bash
python desafio.py
```

## 📚 Conceitos praticados

Durante o desenvolvimento foram utilizados conceitos fundamentais de Python, como:

* Variáveis
* Estruturas condicionais
* Estruturas de repetição
* Listas
* Entrada e saída de dados
* Operações matemáticas
* Tratamento de exceções
* Formatação de strings

## 🎯 Objetivo

O projeto tem caráter educacional e foi desenvolvido para consolidar os fundamentos da programação Python por meio da implementação de um sistema bancário simples executado via terminal.
